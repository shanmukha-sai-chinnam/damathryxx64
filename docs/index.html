// SYSTEM ARCHITECTURE

Zero Drift Declarative Engine

Every package, service, agent runtime, and skill is declared in Nix and pinned via flake.lock. No imperative state. No drift. Full reproducibility.

⚡
Strict NixOS-WSL Target
All commands, builds, MCP servers, and tool executions run inside NixOS-WSL. Zero mutable host pollution. Windows only bridges the language server.
🎯
Dots-Driven Truth
The damathryxx64 flake is the single source of truth. Flake inputs pin reproducible commits for all agent runtimes, skills, and system packages.
🔄
Autonomous Upstream Sync
Daily automated pipeline tracks 5 upstreams (Google, Superpowers, Karpathy, ADHD, Anatomy), merges, rewrites for Antigravity, and audits compliance.
🛡️
5-Stage Validation Pipeline
Alejandra formatting → Statix anti-patterns → Deadnix dead code → Nix flake eval → Closure dry-build. Every change passes all gates before commit.

// ANTIGRAVITY 2.0 HOST BRIDGE

Headless WSL2 Architecture

Antigravity 2.0 runs without the legacy IDE. The Windows host executable connects directly to the NixOS-WSL guest language server.

HOST BRIDGE PROTOCOL
# Windows Host Launcher
PS C:\> Antigravity.exe --connect wsl://NixOS
# Resolves to:
wsl.exe -d NixOS --exec ~/.antigravity-server/bin/language_server
 
# Native Shell Launchers (inside NixOS-WSL)
damathryxx64@nixos $ agy2 # Launch Antigravity 2.0
damathryxx64@nixos $ help-nix # Quick reference card
