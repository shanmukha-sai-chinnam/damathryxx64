Command Reference

All task runners are declared in modules/packages/task-runners.nix and modules/ai/skills.nix, accessible system-wide.

Command Type Declared Behavior
dots-validate Quality Gate Executes 4-stage validation: Alejandra format, Statix anti-patterns, Deadnix dead code, and Nix flake check impure.
dots-build Dry-Run Dry-builds live system derivation via nh os build with visual closure diff (no switch applied).
dots-upgrade System Upgrade Runs dots-validate, updates all flake inputs, and switches the live NixOS system in a single step.
dots-workspace-pull Git Sentinel Pulls all 5 repositories from origin automatically on user login via systemd user service.
dots-workspace-sync Full Pipeline Manual pipeline: pulls all repos + runs dots-validate + executes nh os switch.
dots-sync-skills status Anti-Drift Inspects git divergence across origin and upstreams and compares against flake.lock pins.
refresh-skills Skills Pipeline Automated pipeline: fetch → sync → rewrite foreign providers → audit frontmatter → sync to ~/.gemini/config.
agy2 AI Launcher Launches Antigravity 2.0 on the Windows host, connected to the NixOS-WSL language server.
antigravity-superpowers doctor Diagnostic Verifies agent runtime environments, tool dependencies, and MCP server health.
nix develop .#python devShell Enters isolated Python 3.12 development environment with required language tooling.
