WSL2 Bridge

Antigravity 2.0 Host-to-Guest Interoperability

Eliminating Electron IDE overhead: Windows host process communicates directly with the NixOS-WSL language server.

Legacy Approach (IDE Overhead)

Heavy Host IDE

  • ✕ Heavy Electron memory footprint on Windows host
  • ✕ Imperative plugin and extension drift
  • ✕ Hardcoded Windows paths leaking into Linux projects
  • ✕ Inconsistent CLI environments and terminal latency
Our Architecture (agy2)

Pure NixOS-WSL Headless Bridge

  • ✓ Windows Launcher: Antigravity.exe connects to NixOS guest via direct WSL socket
  • ✓ Native Shell Utility: Run agy2 inside NixOS to launch Windows Antigravity 2.0 attached to WSL
  • ✓ Nix-LD Binary Execution: Pure dynamic link resolver runs standard Linux ELF language servers
  • ✓ Declarative Skills Sync: Skills auto-sync from Nix store paths on user login via systemd user services

Zero Drift Guarantee

4-Stage Pre-Commit Validation Pipeline

Every change to the system undergoes strict automated static checks before any build or commit:

01

Alejandra

Nix Formatting

Strict, opinionated code formatting across all 18+ system nix expressions.

nix fmt -- .
02

Statix

Anti-patterns

Detects code smell, unmanaged mutable paths, and anti-patterns.

statix check .
03

Deadnix

Dead Code

Prunes unused declarations and bindings across flake modules.

deadnix .
04

Flake Check

Closure Evaluation

Evaluates all NixOS configurations, devShells, and derivations.

nix flake check --impure
05

dots-build

Dry-Run Diff

Dry-builds top-level derivation with visual closure diff without switching.

dots-build
Command Reference

Workspace & Agent Task Runners

Declarative shell commands pre-configured in damathryxx64/modules/packages/default.nix:

Command Type Action Quick Copy
dots-validate Quality Gate Full 4-stage pipeline: Alejandra + Statix + Deadnix + flake check
dots-build Dry-Run Dry-builds system derivation with visual closure diff (safe, no switch)
dots-upgrade System Validates quality gates, updates all flake inputs, and applies system switch
dots-sync-skills status Anti-Drift Inspects git divergence and flake lock synchronization across all 5 repos
refresh-skills Skills Sync Pulls upstreams, purges foreign providers, audits frontmatter, syncs to ~/.gemini/config
dots-workspace-pull Git Pull Pulls all 5 workspace repos from origin (runs automatically on login via systemd)
agy2 AI Bridge Launches Antigravity 2.0 on Windows host connected to NixOS WSL
