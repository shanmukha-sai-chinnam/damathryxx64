1. System Overview & Monorepo Architecture

The damathryxx64 monorepo unifies all operating system declarations, development toolchains, AI agent customization profiles, and security daemons into a single hermetic repository. It completely eliminates polyrepo drift, unmanaged mutable machine state, and imperative package installations.

Anti-Drift Guarantee: The damathryxx64 dots repository is the primary driver. All AI agent runtimes, skills, rules, CLI packages, and system configurations are declared in-tree. Every change is verified through the 5-stage automated quality gate (dots-validate).

2. Declarative Configuration Hub (values.json)

Machine paths, usernames, ports, and upstream endpoints are declared once in values.json. The pure Nix loader (lib/values.nix) imports this JSON document hermetically via builtins.fromJSON without rebuilding derivations when only runtime variables change.

3. NixOS-WSL System Modules (modules/)

System modules are partitioned cleanly by operational domain and orchestrated through modules/configuration.nix. Built directly against upstream Nixpkgs unstable with in-tree kernel shims and zero mutable state:

  • modules/system/: Core System & Hardware Lifecycle
    Enforces the WSL2 boot handshake with a 60-second init timeout (wsl.initTimeout = 60000;), preventing spurious timeout aborts on heavy startup loads. Configures zram in-memory compressed swap, systemd-oomd memory pressure sentinels, Cascadia Code and Fira Code Nerd Fonts, binary substituters, Docker Desktop rootless socket permissions (mode 0666), and weekly automated Nix store garbage collection via nh.
  • modules/environment/: Shell Environment & Task Runners
    Deploys an interactive Zsh shell with Starship prompt, direnv nix-direnv caching, Bat, Fzf, Zoxide, native shell tab completions (_agy, _nh, _antigravity_superpowers), development compilers (Python, Node.js 20, GCC, Clang, CMake, uv, nixd), bidirectional Windows clipboard bridge (cb), and the full task runner suite (dots-validate, dots-test-vm, dots-build, dots-switch, dots-val, help-nix).
  • modules/ai/: Agent Runtimes, Skills Sync & MCP Servers
    Integrates the Antigravity CLI and Gemini AI toolkit, in-tree Antigravity Superpowers profile, the declarative agent skills synchronizer (agent-skills-sync.service), and native stdio JSON-RPC MCP servers (TypeSafe Jev, GitHub, NixOS, Git, Filesystem, Fetch, Sequential Thinking).
  • modules/security/: Threat Containment & Policies
    Spawns the user-level systemd service for real-time ClamAV inotify file monitoring across all workspace repositories, enforces passwordless sudo for Nix operations, and configures host firewall rules.

4. Custom In-Tree Package Derivations (pkgs/)

pkgs/clamav-scanner (clamav-sentinel)

A sub-10ms real-time inotify file scanner monitoring workspace file creations via the Linux kernel inotify API. Streams file contents over TCP (127.0.0.1:3310) using the ClamAV INSTREAM protocol to an in-memory Docker container holding 8.5M+ signatures:

  • Relocation: Instantly moves infected files to .quarantine/<ts>_<name>.
  • Permission Stripping: Neutralizes execution privileges with chmod 000.
  • Desktop Notification: Dispatches high-priority desktop alerts via notify-send.
  • Audit Logging: Appends SHA-256 hash, scan latency, and malware signature to clamav-audit.jsonl.

pkgs/antigravity-superpowers

A Node.js 20+ declarative project initializer, environment health diagnostic runner (doctor), and continuous lint/format watcher with automatic fixing (watch --fix) using Alejandra, Statix, Deadnix, and ShellCheck.

nether-ward

8. Architecture Decision Records & Quality Gates

ADR-001: Docker Desktop Socket Integration (Mode 0666)

Docker Desktop v4.90+ provisions user sockets inside /mnt/wsl/docker-desktop/shared-sockets/guest-services with root-only permissions (0600), causing permission denied errors for non-root users inside WSL2. Nether Ward and damathryxx64 solve this via an automated in-tree systemd socket permission watcher that sets permissions to 0666 upon creation, providing seamless container access without requiring unmanaged sudo chmod.

ADR-002: WSL2 Boot Timeout Remediation (`initTimeout = 60000`)

During cold boots with heavy derivation builds or Docker daemon starts, the default WSL init timeout (10 seconds) aborts systemd startup. Nether Ward enforces initTimeout = 60000 inside modules/system/wsl.nix, ensuring robust cold-boot completion under high load.

ADR-003: Pre-Commit 5-Stage Zero Drift Quality Gate

Every commit to damathryxx64 must pass the automated pre-commit validation suite before being pushed:

  1. Stage 1 (Schema Check): Validates values.json syntax and schema compliance against values.schema.json.
  2. Stage 2 (Format Check): Verifies all Nix expressions adhere to Alejandra code formatting style.
  3. Stage 3 (Anti-Pattern Check): Scans for non-idiomatic Nix expressions using Statix.
  4. Stage 4 (Dead Code Check): Identifies unreferenced bindings and dead declarations using Deadnix.
  5. Stage 5 (Flake Evaluation): Executes nix flake check --impure to guarantee hermetic evaluation and lockfile consistency.
