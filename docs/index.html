pkgs/clamav-scanner — Real-Time Inotify Antivirus Daemon

Python 3 + Docker

Sub-10ms latency file scanner monitoring workspace file creations via Linux kernel inotify. Streams file content over TCP socket (127.0.0.1:3310) using ClamAV INSTREAM protocol to an in-memory Docker container with 8.5M+ signatures.

Quarantine Protocol

  • Relocation: Instantly moves infected file to .quarantine/<ts>_<name>
  • Permission Neutralization: Strips all permissions (chmod 000)
  • Desktop Notification: High-priority alert dispatched via notify-send
  • Audit Log: Appends SHA-256, latency, and signature to clamav-audit.jsonl

Docker Desktop v4.90+ Startup Handshake & InitTimeout Remediation

Post-Mortem

Root Cause: Docker Desktop v4.90+ changed its socket creation handshake: it creates proxy sockets owned by root:root with mode 0700 on a mounted tmpfs at /mnt/wsl/docker-desktop/shared-sockets/guest-services, while strict 10s default timeouts caused boot aborts.

Remediation: Added systemd path watcher systemd.paths.docker-desktop-proxy-socket executing an idempotent chmod 0666 script on socket creation, and extended boot timeout to 60,000ms via wsl.initTimeout = 60000;.
